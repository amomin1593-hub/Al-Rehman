# Product photos

Drop photos here, then run `npm run data` and refresh the site.

- One photo for a whole category: name it after the category
  sink-bowls.jpg, bathroom-faucets.jpg, kitchen-faucets.jpg,
  muslim-showers.jpg, showers.jpg, accessories.jpg
- One photo for a single product: name it after the product's slug
  (the last part of its URL), e.g. noor-basin-mixer.jpg

.jpg, .png and .webp all work. Square or 4:5 portrait photos look best.
A product photo wins over a category photo. With no photo, the drawn artwork is shown.
